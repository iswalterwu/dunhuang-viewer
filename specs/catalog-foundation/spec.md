# Feature: catalog-foundation 目录底座（spec.md）

> Spec 阶段产物：按 what/why 写需求，不写技术方案。每条需求必须映射到具体的验收规则。
> 技术方案与实施细节在 plan.md；本文件由 Clarify 阶段持续修订直至无歧义。
> 状态（2026-10-27）：Gate 1 已批准第 1 版。Plan 阶段（Q-011～Q-014）与 Checklist 第 1 轮（Q-015～Q-026）共发现 16 处需求问题，按工作流回到 Clarify 修订为第 2 版，**待 Gate 1 再批准**；批准后冻结。

## 1. 背景与动机（why）

- **身份不稳定**：v0 以「含 TIFF 的目录」为一卷，卷 ID 由磁盘路径派生（architecture.md §3.2），目录一改名，ID 和图块缓存就失效
- **一卷不等于一件文物**：同一件写卷分散在多个目录（法藏 849 个影像目录只对应 740 个编号，22 个编号同时有两类影像）；一个目录也可能涉及多件（名称含多个编号、散放文件）（plan.md §1.3）
- **来源、许可与出处没有记录**：材料来自第三方资料接收（接收事件 A）与 IDP 下载，混有第三方加工图；约 110 个冠以「敦煌遗书」的目录并非敦煌出土或出处待核（plan.md §1.3、D-012、D-015）
- **后续工作需要共同底座**：`name-normalization`、`annotation-workbench`、`catalog-browse` 都要以「写卷」为单位、身份稳定、带编号 / 影像 / 来源 / 出处的目录为基础（plan.md §8）

### 术语

| 术语 | 含义 |
|---|---|
| 写卷 | 一件物理文物（写卷、残片、册页，或刻本、拓本、绘画），目录中的一条记录 |
| 分类目录 | 原图目录的一级子目录（2026-10-27 有 5 个） |
| 批次目录 | 有「批次层」的分类目录下的一级子目录，只是一批材料的容器，本身不是写卷。2026-10-27 登记：`188敦煌001`（`2018年`、`2019年新增1`、`2019年新增2`、`2019年新增3`、`2501-2600`）与 `188 敦煌002`（`202106新增`）有批次层，其余分类没有。登记随规则版本维护；未登记的新分类按「没有批次层」处理，并在报告中提示 |
| 写卷目录 | 批次目录（分类没有批次层时为分类目录）下的一级子目录 |
| 子目录词表 | 写卷目录之下的子目录按名称（精确匹配）分为：**分段类**——名称恰为「分段」「分」「切片」「片」「斷巻分段」「全巻分段」「全巻分」「全卷分」「寫 1巻分段」，或以「分段」「裁」结尾；**版本类**——名称恰为「HD」，或为「本写卷的馆藏号 + HD」（如 `P.2176HD`）；**国图页图**——国图卷的 `pages/`。其余名称为词表外子目录 |
| 写卷单元 | 归并的基本单位：一个写卷目录连同其词表内的子目录；批次目录中的一个散放文件；一个词表外子目录 |
| 影像目录 | v0 意义上的「卷」：直接含 TIFF / BTF 的目录 |
| 影像 | 一个影像文件：TIFF、PSB、国图页图或预览图 JPG |
| 馆藏号 | 收藏机构的编号：伯希和汉文写卷号、国图 BD 号 |
| 合规馆藏号 | 伯希和号落在汉文写卷号段（2001–4099、4500–5043、5522–6038）内；BD 号写作「BD + 5 位数字 + 可选字母后缀」，并与该卷 IIIF 清单的 Pressmark 一致（没有清单时只按写法判定） |
| 存疑编号 | 不合规的馆藏号写法：保留原文、可以检索，但不作主编号、不作归并依据 |
| 主编号 | 写卷的合规馆藏号；没有合规馆藏号的写卷不设主编号 |
| 谱系 | 影像的来源类别：BnF 原图 / 第三方加工图 / 本地合成 / 国图 IDP 下载 / 未判定（plan.md §1.3） |
| 角色 | 影像在写卷中的作用：单幅整卷 / 分段 / 另一版本 / 已迁出的分片 / 合并长卷 / PSB 源文件 / 页图 |
| 出处认定 | 是否敦煌出土：已确认 / 待核 / 非敦煌，附依据（D-015） |

## 2. 目标与非目标

### 目标（what）

- 把全部现有材料导入统一目录，以写卷为单位，每件写卷有稳定的内部 ID
- 每件写卷记录：编号（多体系）、影像（含事实、谱系、角色、派生关系）、来源与许可、出处认定初值、原始记录
- 每个结构化字段可追溯来源、保留历史
- 导入可以反复运行，追踪新增、变化与缺失
- 提供只读查询接口，供授权用户与后续 feature 使用
- 每次导入给出报告与异常清单

### 非目标

- 规范名称，以及题名、时代、尺寸等字段的解析（`name-normalization`）
- 标注、人工认定与修改的界面，写卷的人工合并、拆分与回滚操作（`annotation-workbench`）
- 分类浏览界面、同一写卷多套影像中「首选影像」的选择（`catalog-browse`）
- 采集与关联外部资源，如法藏写卷的 IDP / Gallica 清单（Phase 2）
- 影像服务与查看（继续由 v0 承担）；修改原图目录与 v0；对外开放（D-012）

## 3. 需求条目

### R-001 导入范围

- **what**：导入 D-015 规定的全部现有材料——原图目录 `/srv/example/data` 下 5 个分类中的影像（TIFF / BTF、PSB、国图页图与预览图 JPG）与附件（`.txt` 说明、国图卷的三种 JSON），以及备份目录 `/srv/example/backup` 中的分片。影像目录按 v0 规则识别：跳过以 `@`、`#`、`.` 开头的目录。以 `.` 开头的隐藏文件一并导入（§5 Q-003）。国图卷的整卷预览图（`*_preview.jpg`）作为该写卷的另一版本导入；下载器的图块缓存（`tiles/`）与中间文件（`.npy`）不导入（§5 Q-013）
- **验收规则**：
  - [ ] AC-001-1 导入报告对照 v0 在导入时刻的实际索引（v0 `/api/index`）：索引中的每个影像目录都至少对应一件写卷，未对应的数量为 0；磁盘上已有、但 v0 索引尚未收录的影像目录单独列出（v0 只在启动或重新扫描时更新索引）
  - [ ] AC-001-2 原图目录中每个 TIFF / BTF（含隐藏文件）、备份目录中每个 TIFF、每个 PSB、国图卷 `pages/` 下的每个页图 JPG 与每个预览图 JPG，在目录中有且只有一条影像记录；数量与导入时按本需求的跳过规则统计的磁盘文件数一致
  - [ ] AC-001-3 每个 `.txt` 说明、每个国图卷的 `manifest.json`、`report.json`、`index.json` 作为所属写卷的原始附件导入；一个附件所在目录对应多件写卷时，关联到其中每一件
  - [ ] AC-001-4 未导入的文件与目录（隐藏目录、系统目录、下载器的图块缓存 `tiles/` 与中间文件 `.npy`）逐一列在导入报告中并注明原因

### R-002 写卷的识别与归并

- **what**：按「一件物理文物一条记录」，以写卷单元为单位把影像归入写卷（术语见 §1；§5 Q-001、Q-002、Q-005、Q-011、Q-012、Q-015、Q-024）：
  1. 同一**合规馆藏号**（含分件）的写卷单元归入同一件写卷，不论分散在几个目录、属于哪个谱系；存疑编号不作归并依据
  2. 写卷目录下的分段类与版本类子目录、国图 `pages/` 归入该写卷目录的写卷单元；词表外的子目录自成写卷单元，并列入异常待核
  3. 直接放在批次目录里的散放影像文件，每个文件自成写卷单元
  4. 名称含多个合规馆藏号的写卷单元，每个编号一件写卷，单元中的影像同时关联到这几件
  5. 分件写法各成一件写卷，并记录母号；母号本身也有写卷单元时另成一件
  6. 没有合规馆藏号的写卷单元各成一件写卷，不自动合并；疑似同一件的只列为合并建议。分享者自编号（`WB`、`WA`）与《开宝藏》帙号不作归并依据，只用来提出合并建议
  7. 备份目录的分片按其在备份目录中的相对位置，归入原图目录中对应的写卷单元
- **验收规则**：
  - [ ] AC-002-1 同一合规馆藏号的全部影像归入同一件写卷；例：P.2002 的 BnF 原图影像目录与第三方加工图影像归入同一件写卷，两套影像都在
  - [ ] AC-002-2 分段类子目录的影像归入写卷，角色为「分段」；版本类为「另一版本」；国图 `pages/` 为「页图」；词表外子目录自成一件写卷并列入异常（2026-10-27 有 1 个：WB 30 目录下的「明清仿古粉本」）
  - [ ] AC-002-3 散放影像文件各成一件写卷（2026-10-27 有 7 个，均在 `188敦煌001/2018年`），编号从文件名解析（如「（P.4508）」→ `P.4508`）
  - [ ] AC-002-4 名称含多个合规馆藏号的影像目录（2026-10-27 有 7 个，如 `P3012+5564`、`P2661(+3735)`）：每个编号各成一件写卷，影像同时关联到这几件，写卷上记有「名称所示的合装或缀合」线索
  - [ ] AC-002-5 分件写法（`P.2504-1Pièce`、`P.2006-1`、`P.2222A`、`P2842-P2`、`BD00023a`）各成一件写卷并记录母号；按母号能查到它的全部分件（如 P.2504 的 4 个分件）
  - [ ] AC-002-6 没有合规馆藏号的写卷单元各成一件写卷，不自动合并：名称只差「上部 / 下部」「上卷 / 下卷」「紙背」的成对单元、使用同一分享者自编号的单元（如 WB 29 的两个目录）、使用同一《开宝藏》帙号的单元，都只列入合并建议清单
  - [ ] AC-002-7 备份目录的分片全部归入原写卷（2026-10-27 核查为 925/925），角色为「已迁出的分片」并记录原位置；对不上的列入异常
  - [ ] AC-002-8 存疑编号不触发归并：使用 `P.0901` 的 3 个目录（绢画、梵文写经、坐佛像）各成一件写卷

### R-003 稳定身份

- **what**：每件写卷、每条影像有内部 ID：不由磁盘路径派生，一经分配不再改变、不复用。身份规则（§5 Q-016、Q-017）：
  - **影像**：同一位置的文件内容变化，仍是同一影像（记变化历史）；同一文件在同一根目录内改名或移动，仍是同一影像；不能唯一确认是同一文件时，不猜测延续，视为新影像并列入「身份待确认」异常
  - **写卷**：以影像为准——写卷单元的影像多数已属于某件写卷时沿用该写卷，编号随目录名更新；因编号相同而需合并的两件写卷，保留较早登记的 ID，被并入的 ID 永久保留并指向保留者；不自动拆分写卷
- **验收规则**：
  - [ ] AC-003-1 同一份数据连续导入两次，所有写卷与影像的内部 ID 完全相同，不产生重复记录
  - [ ] AC-003-2 在测试数据中把一个影像目录改名、或移到同一根目录下的另一个批次目录后重新导入，写卷 ID 与影像 ID 不变，旧路径记入路径历史
  - [ ] AC-003-3 内部 ID 不含磁盘路径信息，也不能由路径计算得到
  - [ ] AC-003-4 目录改名导致馆藏号变化、而影像未变时，写卷 ID 不变，编号更新，旧编号记入编号历史
  - [ ] AC-003-5 两件写卷因合规馆藏号相同而合并时，保留较早登记的写卷 ID；被并入的 ID 不删除、不复用，按旧 ID 查询返回保留的写卷并注明已并入；双方都有人工出处结论且不一致时，保留方的结论不变，另一方的结论记入历史并列入异常
  - [ ] AC-003-6 规则要求把一件写卷的影像分到多件写卷时，不自动拆分：保持原样，并列入异常待人工确认
  - [ ] AC-003-7 不能唯一确认身份时不猜测延续（用测试数据验证：同一内容的重复副本；在另一根目录出现的同名同大小文件；文件编号被复用），这些情况都作为新影像导入并列入「身份待确认」异常

### R-004 编号

- **what**：每件写卷记录全部编号：体系、原文写法、规范写法、出处（目录名 / 文件名 / IIIF 清单）、是否主编号、合规或存疑。2026-10-27 已知的体系：BnF 伯希和汉文写卷号（`P.`）、国图 BD 号、分享者自编号（`WB`、`WA`）、《开宝藏》千字文帙号；国图卷 IIIF 清单中的 IDP 条目 ID 作为外部编号（§5 Q-015、Q-018、Q-026）
- **验收规则**：
  - [ ] AC-004-1 伯希和编号的各种写法（`P2602`、`P.2033`、`P. 0901`、`p.2731`、`Pelliot chinois 2002`）解析为统一的规范写法（如 `P.2602`），原文写法逐字保留；没有前缀的数字（如 `4518(35)`）不解析为伯希和号，列入「疑似编号」异常
  - [ ] AC-004-2 不在伯希和汉文写卷号段内的 P 号标为存疑并列入异常（2026-10-27 为 P.0901、P.5257）；存疑编号保留原文、可以检索，不作主编号、不作归并依据
  - [ ] AC-004-3 国图卷以 IIIF 清单的 Pressmark 为馆藏号；目录名中的 BD 号与 Pressmark 不一致时，以 Pressmark 为准，目录名中的号记为存疑并列入异常；没有清单的国图卷，按写法合规的目录名 BD 号建立写卷，并列入「缺少清单」异常；清单的 IDP 条目 ID 记为外部编号
  - [ ] AC-004-4 `WB`、`WA` 记为「分享者自编号」体系，《开宝藏》帙号（如「令字」）记为「开宝藏帙号」体系，两者都不作为主编号，也不作为归并依据（R-002）
  - [ ] AC-004-5 每件写卷最多一个主编号，且只能是合规馆藏号；只有分享者自编号、存疑编号或没有编号的写卷，主编号为空

### R-005 影像记录与谱系

- **what**：每条影像记录文件位置（相对路径与路径历史）、文件大小、事实字段、谱系、角色、派生关系，以及国图卷对应的 IIIF 画布。事实字段按文件种类区分，每个字段的取值为「有值」「不适用」「缺失」（文件中没有该信息）之一（§5 Q-019）。谱系按 plan.md §1.3 的判定依据逐个文件判定
- **验收规则**：
  - [ ] AC-005-1 事实字段：TIFF 记像素尺寸、色彩模式、位深、分辨率、压缩方式、软件标签；PSB 记像素尺寸、通道数、位深、色彩模式（分辨率、压缩方式、软件标签为「不适用」）；JPG 记像素尺寸、色彩模式，分辨率按文件内信息为「有值」或「缺失」。读不了的文件列入异常，不中断导入
  - [ ] AC-005-2 每条影像都有谱系；判不出的标为「未判定」并列入异常。目录级汇总：一个影像目录的源影像谱系一致时取该谱系，不一致时记为「混合」。用 2026-10-27 数据导入时，汇总结果与核查一致（BnF 原图 447、第三方加工图 499、本地合成 12），不一致的逐项说明原因
  - [ ] AC-005-3 12 个 `合并长卷.tif` 记录派生来源：由分段拼接的关联到源分片（含备份目录中的），由 PSB 转换的关联到源 PSB，依据为 `cache/` 中 2026-10-21 的执行记录；不能确定的列入异常
  - [ ] AC-005-4 国图卷每个本地 TIFF 对应到 IIIF 清单中的画布（依据 `report.json`；2026-10-27 抽查 1,044/1,044 可对应），对不上的列入异常
  - [ ] AC-005-5 同一件写卷有多套影像时全部保留，并能区分每套影像的来源目录与谱系

### R-006 来源与许可

- **what**：每条影像记录收藏机构、获取渠道、许可条款、署名文本与展示策略，按 D-012 的默认规则自动填写，并标明该值来自默认规则
- **验收规则**：
  - [ ] AC-006-1 每条影像的这五个字段都有显式取值（含「未知」「无」），且与 D-012 默认规则表一致：国图卷为 IDP 条款，署名取自清单（The National Library of China）；法藏 BnF 原图为 Gallica 条款；第三方加工图、日藏与其他材料为「未知」；本地合成继承源影像中最严格的一项
  - [ ] AC-006-2 每件写卷的展示策略取其全部影像中最严格的一项；Phase 1 所有写卷只在登录墙内可见
  - [ ] AC-006-3 获取渠道落到具体的转存或下载事件（如「第三方资料接收（接收事件 A；私人日期非公开）」「IDP IIIF 下载」），可在 plan.md §1.4 中查到对应记录

### R-007 出处认定初值

- **what**：每件写卷有出处认定（已确认 / 待核 / 非敦煌），附依据、判定者（规则或人）与时间。导入只按规则给初值；「非敦煌」只能由人确认（§5 Q-004、Q-020）
- **验收规则**：
  - [ ] AC-007-1 每件写卷都有出处认定、依据、判定者与时间，没有空值
  - [ ] AC-007-2 带合规馆藏号、且没有非敦煌线索的写卷为「已确认」；其余为「待核」
  - [ ] AC-007-3 plan.md §1.3「并非都是敦煌写卷」所列的 18 个《开宝藏》目录，以及题名带明确线索的目录（清光绪写本、北齐尖山刻经、室町写、竹生島経、紫紙金字金光明最勝王経、大橋家来翰集），对应写卷为「待核」并附「建议：非敦煌」及依据；若同时带有合规馆藏号，依据中同时列出两者，并列入「出处证据冲突」异常；导入不把任何写卷直接定为「非敦煌」

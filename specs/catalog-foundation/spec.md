> 技术方案与实施细节在 plan.md；本文件由 Clarify 阶段持续修订直至无歧义。
> 状态（2026-10-27）：Gate 1 已批准第 1 版。Plan 阶段（Q-011～Q-014）、Checklist 第 1 轮（Q-015～Q-026）与第 2 轮（Q-027～Q-037）共发现 27 处需求问题，按工作流回到 Clarify 修订为第 3 版，**待 Gate 1 再批准**；批准后冻结。

## 1. 背景与动机（why）

- **身份不稳定**：v0 以「含 TIFF 的目录」为一卷，卷 ID 由磁盘路径派生（architecture.md §3.2），目录一改名，ID 和图块缓存就失效
- **一卷不等于一件文物**：同一件写卷分散在多个目录（法藏 849 个影像目录只对应 740 个编号，22 个编号同时有两类影像）；一个目录也可能涉及多件（名称含多个编号、散放文件）（plan.md §1.3）
- **来源、许可与出处没有记录**：材料来自第三方资料接收（接收事件 A）与 IDP 下载，混有第三方加工图；约 110 个冠以「敦煌遗书」的目录并非敦煌出土或出处待核（plan.md §1.3、D-012、D-015）
- **后续工作需要共同底座**：`name-normalization`、`annotation-workbench`、`catalog-browse` 都要以「写卷」为单位、身份稳定、带编号 / 影像 / 来源 / 出处的目录为基础（plan.md §8）

### 术语

| 术语 | 含义 |
|---|---|
| 写卷 | 一件物理文物（写卷、残片、册页，或刻本、拓本、绘画），目录中的一条记录 |
| 分类目录 | 原图目录的一级子目录（2026-10-27 有 5 个） |
| 批次目录 | 有「批次层」的分类目录下的一级子目录，只是一批材料的容器，本身不是写卷。2026-10-27 登记：`188敦煌001`（`2018年`、`2019年新增1`、`2019年新增2`、`2019年新增3`、`2501-2600`）与 `188 敦煌002`（`202106新增`）有批次层，其余分类没有。登记随规则版本维护；未登记的新分类按「没有批次层」处理，并在报告中提示 |
| 写卷目录 | 批次目录（分类没有批次层时为分类目录）下的一级子目录 |
| 子目录词表 | 写卷目录之下的子目录按名称（精确匹配）分为：**分段类**——名称恰为「分段」「分」「切片」「片」「斷巻分段」「全巻分段」「全巻分」「全卷分」「寫 1巻分段」，或以「分段」「裁」结尾；**版本类**——名称恰为「HD」，或为「本写卷的馆藏号 + HD」（如 `P.2176HD`）；**国图页图**——国图卷的 `pages/`。其余名称为词表外子目录 |
| 写卷单元 | 归并的基本单位：一个写卷目录连同其词表内的子目录；不在任何写卷目录中的一个散放影像文件（直接放在批次目录，或没有批次层的分类目录里）；一个词表外子目录。子目录中的附件归入该子目录所属的单元。只有含可导入影像（直接或更深层）的目录才构成写卷单元；不含可导入影像的子目录（如国图 `tiles/`）整体记入未导入清单。单元的编号取自：写卷目录名（词表内子目录沿用它）、散放文件的文件名、词表外子目录自己的名称（不继承父目录的编号）；国图卷另取清单 Pressmark |
| 影像目录 | v0 意义上的「卷」：直接含 TIFF / BTF 的目录 |
| 影像 | 一个影像文件：TIFF、PSB、国图页图或预览图 JPG |
| 馆藏号 | 收藏机构的编号：伯希和汉文写卷号、国图 BD 号 |
| 合规馆藏号 | 伯希和号落在汉文写卷号段（2001–4099、4500–5043、5522–6038）内；BD 号写作「BD + 5 位数字 + 可选字母后缀」，并与该卷 IIIF 清单的 Pressmark 一致（没有清单时只按写法判定） |
| 存疑编号 | 不合规的馆藏号写法：保留原文、可以检索，但不作主编号、不作归并依据 |
| 主编号 | 写卷的合规馆藏号；没有合规馆藏号的写卷不设主编号 |
| 谱系 | 影像的来源类别：BnF 原图 / 第三方加工图 / 本地合成 / 国图 IDP 下载 / 未判定（plan.md §1.3） |
| 角色 | 影像在写卷中的作用：单幅整卷 / 分段 / 另一版本 / 已迁出的分片 / 合并长卷 / PSB 源文件 / 页图 |
| 出处认定 | 是否敦煌出土：已确认 / 待核 / 非敦煌，附依据（D-015） |

## 2. 目标与非目标

### 目标（what）

- 把全部现有材料导入统一目录，以写卷为单位，每件写卷有稳定的内部 ID
- 每件写卷记录：编号（多体系）、影像（含事实、谱系、角色、派生关系）、来源与许可、出处认定初值、原始记录
- 每个结构化字段可追溯来源、保留历史
- 导入可以反复运行，追踪新增、变化与缺失
- 提供只读查询接口，供授权用户与后续 feature 使用
- 每次导入给出报告与异常清单

### 非目标

- 规范名称，以及题名、时代、尺寸等字段的解析（`name-normalization`）
- 标注、人工认定与修改的界面，写卷的人工合并、拆分与回滚操作（`annotation-workbench`）
- 分类浏览界面、同一写卷多套影像中「首选影像」的选择（`catalog-browse`）
- 采集与关联外部资源，如法藏写卷的 IDP / Gallica 清单（Phase 2）
- 影像服务与查看（继续由 v0 承担）；修改原图目录与 v0；对外开放（D-012）

## 3. 需求条目

### R-001 导入范围

- **what**：导入 D-015 规定的全部现有材料——原图目录 `/srv/example/data` 下 5 个分类中的影像（TIFF / BTF、PSB、国图页图与预览图 JPG）与附件（`.txt` 说明、国图卷的三种 JSON），以及备份目录 `/srv/example/backup` 中的分片。影像目录按 v0 规则识别：跳过以 `@`、`#`、`.` 开头的目录。以 `.` 开头的隐藏文件一并导入（§5 Q-003）。国图卷的整卷预览图（`*_preview.jpg`）作为该写卷的另一版本导入；下载器的图块缓存（`tiles/`）与中间文件（`.npy`）不导入（§5 Q-013）。只有附件、没有影像的写卷目录不建写卷，列入「缺少影像」异常（§5 Q-033）
- **验收规则**：
  - [ ] AC-001-1 导入报告对照 v0 在导入时刻的实际索引（v0 `/api/index`）：索引中、且磁盘上仍存在的每个影像目录都至少对应一件写卷，未对应的数量为 0；磁盘上已有、但 v0 尚未收录的影像目录，以及 v0 仍在索引、磁盘上已不存在的目录，各自单列（v0 只在启动或重新扫描时更新索引）。取不到有效索引（调用失败，或 v0 报告索引未就绪）时，导入照常完成，但报告标明「v0 覆盖对照不可验证」及原因并记异常；本条以取得有效索引的导入为准（§5 Q-032）
  - [ ] AC-001-2 原图目录中每个 TIFF / BTF（含隐藏文件）、备份目录中每个 TIFF、每个 PSB、国图卷 `pages/` 下的每个页图 JPG 与每个预览图 JPG，在目录中有且只有一条影像记录；数量与导入时按本需求的跳过规则统计的磁盘文件数一致
  - [ ] AC-001-3 每个 `.txt` 说明、每个国图卷的 `manifest.json`、`report.json`、`index.json` 作为所属写卷的原始附件导入（子目录中的附件归入该子目录所属的单元）；一个附件所在的单元对应多件写卷时，关联到其中每一件；只有附件、没有影像的写卷目录不建写卷，列入「缺少影像」异常
  - [ ] AC-001-4 未导入的文件与目录（隐藏目录、系统目录、下载器的图块缓存 `tiles/` 与中间文件 `.npy`）逐一列在导入报告中并注明原因

### R-002 写卷的识别与归并

- **what**：按「一件物理文物一条记录」，以写卷单元为单位把影像归入写卷（术语见 §1；§5 Q-001、Q-002、Q-005、Q-011、Q-012、Q-015、Q-024）：
  1. 同一**合规馆藏号**（含分件）的写卷单元归入同一件写卷，不论分散在几个目录、属于哪个谱系；存疑编号不作归并依据
  2. 写卷目录下的分段类与版本类子目录、国图 `pages/` 归入该写卷目录的写卷单元，沿用写卷目录的编号；含可导入影像的词表外子目录自成写卷单元，编号取自它自己的名称（不继承父目录），并列入异常待核（§5 Q-033、Q-034）
  3. 不在任何写卷目录中的散放影像文件（直接放在批次目录，或没有批次层的分类目录里），每个文件自成写卷单元
  4. 名称含多个合规馆藏号的写卷单元，每个编号一件写卷，单元中的影像同时关联到这几件
  5. 分件写法各成一件写卷，并记录母号；母号本身也有写卷单元时另成一件
  6. 没有合规馆藏号的写卷单元各成一件写卷，不自动合并；疑似同一件的只列为合并建议。分享者自编号（`WB`、`WA`）与《开宝藏》帙号不作归并依据，只用来提出合并建议
  7. 备份目录的分片按其在备份目录中的相对位置，归入原图目录中对应的写卷单元
- **验收规则**：
  - [ ] AC-002-1 同一合规馆藏号的全部影像归入同一件写卷；例：P.2002 的 BnF 原图影像目录与第三方加工图影像归入同一件写卷，两套影像都在
  - [ ] AC-002-2 分段类子目录的影像归入写卷，角色为「分段」；版本类为「另一版本」；国图 `pages/` 为「页图」；含可导入影像的词表外子目录自成一件写卷并列入异常（2026-10-27 有 1 个：WB 30 目录下的「明清仿古粉本」，不继承 WB 30）；测试数据中，父目录为 P.2002、词表外子目录名为 P.2003 时，子目录归入 P.2003；国图 `tiles/` 等不含可导入影像的子目录不成单元、不计入词表外子目录
  - [ ] AC-002-3 散放影像文件各成一件写卷（2026-10-27 有 8 个：7 个 TIFF、1 个 PSB，均在 `188敦煌001/2018年`），编号从文件名解析（如「（P.4508）」→ `P.4508`）
  - [ ] AC-002-4 名称含多个合规馆藏号的影像目录（2026-10-27 有 7 个，如 `P3012+5564`、`P2661(+3735)`）：每个编号各成一件写卷，影像同时关联到这几件，写卷上记有「名称所示的合装或缀合」线索
  - [ ] AC-002-5 分件写法（`P.2504-1Pièce`、`P.2006-1`、`P.2222A`、`P2842-P2`、`BD00023a`）各成一件写卷并记录母号；按母号能查到它的全部分件（如 P.2504 的 4 个分件）
  - [ ] AC-002-6 没有合规馆藏号的写卷单元各成一件写卷，不自动合并：名称只差「上部 / 下部」「上卷 / 下卷」「紙背」的成对单元、使用同一分享者自编号的单元（如 WB 29 的两个目录）、使用同一《开宝藏》帙号的单元，都只列入合并建议清单
  - [ ] AC-002-7 备份目录的分片全部归入原写卷（2026-10-27 核查为 925/925），角色为「已迁出的分片」并记录原位置；对不上的列入异常
  - [ ] AC-002-8 存疑编号不触发归并：使用 `P.0901` 的 3 个目录（绢画、梵文写经、坐佛像）各成一件写卷

### R-003 稳定身份

- **what**：每件写卷、每条影像有内部 ID：不由磁盘路径派生，一经分配不再改变、不复用。身份规则（§5 Q-016、Q-017、Q-027～Q-030）：
  - **影像**：
    1. 同一位置（同一根目录下的同一相对路径）的文件，内容变化后仍是同一影像，记变化历史
    2. 新位置上的文件，与一条本次不在原位置的影像同在一个根目录，且文件编号、大小、修改时间与抽样内容都相同、一一对应时，是同一影像（改名或移动），记路径历史
    3. 其余情况不猜测延续，作为新影像；与已有影像部分相符的（内容相同、文件编号相同，或对应不唯一）列入「身份待确认」异常
  - **写卷**：以影像为准。全部判断以本次导入前的状态为依据，结果同时生效，与处理顺序无关；「单元的编号」指单元本次按 §1「写卷单元」所列来源解析出的合规馆藏号，「持有」指写卷当前的主编号：
    1. 单元的编号中仍有的，原持有它的写卷继续持有（多编号单元中的每一件各自持有）
    2. 单元的编号变了：恰好有一个单元的编号不被单元中的写卷持有、恰好有一件写卷不持有单元的任何编号时，这件写卷改用这个编号（ID 不变，旧编号记入编号历史）；单元已没有编号时，其中的写卷保留 ID、不再有主编号；其余对不上的情况，不持有单元编号的写卷保持原样，列入「身份待确认」
    3. 一件写卷本次仍在的影像分布在几个单元、而这些单元得出的结果不同时，不自动拆分：写卷保持原样，列入「规则要求拆分」（同一编号分散在几个目录，结果相同，不算）；影像本次都不在的写卷保持原样（R-009）。有写卷列入「身份待确认」或「规则要求拆分」的单元称为待确认单元
    4. 结果中编号相同的写卷合并：保留较早登记的 ID，被并入的 ID 永久保留并指向保留者
    5. 单元中的新影像：正常单元归入持有单元编号的写卷（多编号单元为其中每一件）；没有编号的单元与待确认单元，归入单元中已有影像最多的那件写卷，并列时取较早登记者（只计已有影像）
    6. 单元中没有已有影像时，以及正常单元中不被单元中的写卷持有的编号（如名称新增了一个编号），按 R-002 处理：归入持有该编号的写卷，没有则新建，单元的影像关联到它；待确认单元中对不上的编号本次不建写卷
    7. 已有影像与写卷的关联只因合并（随写卷转到保留者）或第 6 条（增加关联）而改变，不因规则推断移出原写卷
- **验收规则**：
  - [ ] AC-003-1 同一份数据连续导入两次，所有写卷与影像的内部 ID 完全相同，不产生重复记录
  - [ ] AC-003-2 在测试数据中把一个影像目录改名、或移到同一根目录下的另一个批次目录后重新导入，写卷 ID 与影像 ID 不变，旧路径记入路径历史
  - [ ] AC-003-3 内部 ID 不含磁盘路径信息，也不能由路径计算得到
  - [ ] AC-003-4 目录改名导致馆藏号变化、而影像未变时，写卷 ID 不变，编号更新，旧编号记入编号历史
  - [ ] AC-003-5 两件写卷因合规馆藏号相同而合并时，保留较早登记的写卷 ID；被并入的 ID 不删除、不复用，按旧 ID 查询返回保留的写卷并注明已并入；双方都有人工出处结论且不一致时，保留方的结论不变，另一方的结论记入历史并列入异常
  - [ ] AC-003-6 规则要求把一件写卷的影像分到多件写卷时，不自动拆分：保持原样，并列入异常待人工确认
  - [ ] AC-003-7 不能唯一确认身份时不猜测延续（用测试数据验证：同一内容的重复副本；在另一根目录出现的内容相同的文件；文件编号被复用、大小与抽样内容相同而修改时间不同的文件；一个新位置对应多条旧影像，或多个新位置对应同一条旧影像），这些情况都作为新影像导入并列入「身份待确认」异常（§5 Q-030）
  - [ ] AC-003-8 新影像的归属如 R-003 写卷第 5 条（用测试数据验证：无编号目录新增的文件多于原有文件后，写卷 ID 不变、不新建写卷；无编号目录中的已有影像平均分属两件写卷时，新影像归入较早登记者；多编号单元的新影像同时归入每一件）
  - [ ] AC-003-9 编号变化的处理与顺序无关（用测试数据验证：两个目录互换编号、连续变号后，各写卷保留原 ID 并分别更新编号，不发生合并；打乱处理顺序结果相同）
  - [ ] AC-003-10 多编号单元连续导入两次，写卷 ID、关联与编号都不变，不产生异常；名称中增加一个编号时（如 `P2661` 改为 `P2661(+3735)`），为该编号新建或并入已有写卷并共享影像，原写卷不变；名称中的一个编号改写时（如 `P3012+5564` 改为 `P3012+5565`），只有原持有 `P.5564` 的写卷改用新编号
  - [ ] AC-003-11 对不上的情况保持原样（用测试数据验证：多编号单元的两个编号同时改变；另一件写卷的影像被移入一个有编号的目录）：相关写卷不变并列入「身份待确认」，该单元中对不上的编号本次不建写卷

### R-004 编号

- **what**：每件写卷记录全部编号：体系、原文写法、规范写法、出处（目录名 / 文件名 / IIIF 清单）、是否主编号、合规或存疑。2026-10-27 已知的体系：BnF 伯希和汉文写卷号（`P.`）、国图 BD 号、分享者自编号（`WB`、`WA`）、《开宝藏》千字文帙号；国图卷 IIIF 清单中的 IDP 条目 ID 作为外部编号（§5 Q-015、Q-018、Q-026）
- **验收规则**：

### R-005 影像记录与谱系

- **what**：每条影像记录文件位置（相对路径与路径历史）、文件大小、事实字段、谱系、角色、派生关系，以及国图卷对应的 IIIF 画布。事实字段按文件种类区分，每个字段的取值为「有值」「不适用」（该种文件不记此字段）「缺失」（文件中没有该信息）之一（§5 Q-019）。谱系逐个文件判定：TIFF 按 plan.md §1.3 的判定依据，PSB 与国图卷的影像见 AC-005-2
- **验收规则**：

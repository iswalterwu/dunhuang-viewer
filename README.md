# dunhuang-viewer

敦煌开放资源研究平台（建设中）：面向敦煌研究者，梳理并关联写卷、壁画、研究论文与参考资料。
第一阶段整理 NAS 上现有的敦煌写卷影像（标注、分类、命名规范）。

当前在线的是 v0：NAS 上的高清查看器，直读 TIFF 扫描件、生成缩放图块，供电脑、手机、平板浏览器浏览。

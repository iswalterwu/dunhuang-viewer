# D-012 开放范围与影像许可

> 公开隐私修订：私人部署实例与原件非公开保全；历史验证为脱敏衍生记录，不是逐字原文。配置占位不代表真实主机。

- 日期：2026-10-27
- 状态：accepted（plan.md PD-10、PD-11，用户按建议确认）

## 背景

D-010 把项目定位为面向研究者的开放平台，但现有影像的来源与许可各不相同（plan.md §1.3）：

- 国图 BD 卷经 IDP 下载；IDP 内容默认仅限个人或非商业复用，商业使用须向收藏机构申请授权
- 法藏乙类是 BnF 原图，甲类是第三方加工图，两者都经第三方资料接收（接收事件 A），转存本身不构成任何授权；Gallica 允许免费的非商业复用，须注明出处
- 日藏、《开宝藏》刻本等其他材料的收藏方未知

## 备选方案

- 现在就公开浏览（PD-10 B）
- 不区分来源与许可，一律展示（PD-11 B）

## 结论

1. Phase 1 维持登录墙（D-007），只对所有者与授权用户开放；开放范围与协作方式在 Phase 3 另行决定
2. 每个影像都记录：收藏机构、获取渠道、许可条款、署名文本、展示策略
3. 默认规则：

| 影像来源 | 许可 | 署名 | 登录墙内 | 对外（Phase 3 起） |
|---|---|---|---|---|
| 国图 BD 卷（经 IDP 下载） | IDP 条款：个人或非商业复用 | The National Library of China | 可展示 | 链接 IDP |
| 法藏乙类（BnF 原图，经第三方资料接收（接收事件 A）） | Gallica 条款：非商业免费复用，注明出处 | 按 Gallica 条款注明出处 | 可展示 | 链接 Gallica / IDP 的原图 |
| 法藏甲类（第三方加工图） | 未知（第三方衍生） | — | 仅供研究使用 | 不展示本地图，链接原机构 |
| 日藏、《开宝藏》刻本等其他材料 | 未知 | — | 仅供研究使用 | 不展示，待确认来源 |
| 本地合成（`合并长卷.tif` 等） | 继承源影像中最严格的一项 | 同源影像 | 同源影像 | 同源影像 |

4. 对外展示一律优先使用原机构的 IIIF 影像；许可不明的本地影像不对外

## 取舍理由

先合规、后开放。本地高清影像在研究场景下价值最大，但再分发的风险由平台承担；原机构的 IIIF 服务已经覆盖大部分法藏与国图卷，对外链接即可满足浏览需求。

# D-011 前后端分离

- 日期：2026-10-27
- 状态：accepted

## 背景

v0 是 FastAPI 单体，同时提供页面、图块与接口（D-002、D-004）。2026-10-27 用户计划把项目前后端分离。

## 备选方案

- 维持 v0 单体

## 结论

后端以 API 提供数据与影像；前端独立开发、独立部署，只通过 API 访问后端。

## 取舍理由

用户确定的方向。

## 影响

- 分离方式（渐进 / 重写）、数据库、前端框架、影像服务方案待定：`plan.md` PD-17、PD-18
- D-002（单体）与 D-004（原生前端）在迁移完成后由新 ADR 取代；迁移期间 v0 继续在线
- `architecture.md`、`designUI.md` 当前描述 v0，目标架构与新前端设计在 PD-17 确认后补充

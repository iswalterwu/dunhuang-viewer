# D-015 Phase 1 纳入范围与出处认定

- 日期：2026-10-27
- 状态：accepted（plan.md PD-16、PD-19，用户按建议确认）

## 背景

现有材料除主目录影像外，还有备份目录的分片、只有 JPG 页图的国图卷、附带页图的国图卷、隐藏文件与 PSB（plan.md §1.3、§1.4）。
分享者给几乎所有目录都加了「敦煌遗书」前缀，但约 110 个目录并非藏经洞写本或出处待核，包括北宋《开宝藏》刻本、日本古写经、清代写本与刻经拓本等（plan.md §1.3）。

## 备选方案

- 只收主目录的影像，其余材料不纳入
- 把非敦煌与出处待核的材料移出项目范围（PD-19 B）

## 结论

1. Phase 1 目录纳入全部现有材料，作为写卷的影像或派生来源：主目录影像、备份目录的 925 个分片、2 个只有 JPG 页图的国图卷、国图卷附带的页图、16 个 PSB
2. 40 个隐藏文件逐个确认后再定
3. 国图卷的题名在 Phase 1 补齐，按 D-014 的流程（AI 预标 + 抽检）
4. 每件写卷有「出处认定」：已确认 / 待核 / 非敦煌，并附依据；不从目录名继承
5. 非敦煌与待核的材料保留在目录中，默认不进入敦煌分类浏览；认定结果可随时调整

## 取舍理由

- 全部纳入不丢信息：备份分片是合并长卷的来源，页图与 PSB 是原始素材
- 非敦煌材料对书法研究仍有参考价值，标记后保留比移出更稳妥
- 出处认定作为独立字段，防止目录名中的误标扩散到分类与检索（plan.md RK-14）

## 影响

- `catalog-foundation`：导入范围、影像派生关系、出处认定字段
- `catalog-browse`：默认只浏览已确认为敦煌出土的材料

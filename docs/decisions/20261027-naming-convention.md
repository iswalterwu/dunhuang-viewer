# D-013 命名规范

- 日期：2026-10-27
- 状态：accepted（plan.md PD-12、PD-13，用户按建议确认）

## 背景

现有目录名混乱：编号写法不一、法式逗号小数、小数逗号丢失、分享者前缀与尾标、繁简混用（plan.md §4.4）。
v0 的卷 / 文件 ID 与图块缓存键都由磁盘路径派生，改磁盘名会让约 517 万个图块文件失效，也会让下载器的写入路径失配（plan.md RK-12）。

## 备选方案

- 同时修改磁盘目录名与文件名（PD-12 B）
- 编号写作「伯2053」；题名用简体或原卷字形；名称带时代与尺寸（PD-13 的其他选项）

## 结论

1. 「修改命名」只在目录层生效：每件写卷有规范名称，磁盘上的目录名与文件名不改；确需改磁盘时另立 feature，并先登记 ADR
2. 原始名称（目录名、文件名、IIIF 清单字段）逐字永久保留
3. 规范名称 =「主编号 + 规范题名（卷次·品名）」，由结构化字段生成，不手写
4. 编号写法统一为 `P.2053`、`BD00001`、`S.2598`；旧编号与别号作为检索项
5. 题名用规范繁体，检索时繁简互通
6. 时代、尺寸、材质等作为字段，不进入名称；分享者加的前缀（「敦煌遗书」「法藏」等）与尾标（`-`、`+`）不进入名称，只留在原始名称里
7. 尺寸字段统一为「高 × 长 cm」，保留原文与换算依据

## 取舍理由

- 目录层改名零风险、可回滚，不影响 v0 与下载器
- 规范繁体与古籍原貌、学界目录一致；繁简互通保证检索不受字形影响
- 名称只放身份信息，其余信息作为字段，便于排序、筛选与再生成

## 影响

- `name-normalization`：字段解析与规范名称生成
- v0 查看器与图块缓存不受影响

# D-014 标注体系与标注流程

- 日期：2026-10-27
- 状态：accepted（plan.md PD-14、PD-15，用户按建议确认）

## 背景

Phase 1 要为现有材料做细致的标注与分类（D-010）。学界有多部细致的编目，标签方式各不相同；用户没有指定蓝本（plan.md §9.0 Q-04）。
现有影像目录约 6,000 个，纯人工标注工作量过大（plan.md RK-10）。

## 备选方案

- 只由所有者人工标注（PD-15 A）
- 开放协作标注（PD-15 C）

## 结论

1. Phase 1 必选字段：主编号、出处认定、载体类型、题名 / 文本、文献类型、时代、书体、形制（材质、尺寸、行款、存况）
2. 区域级标注先只做题记；单字等其他区域级标注以后再定
3. 蓝本：
   - 著录字段参照国图《中国国家图书馆藏敦煌遗书总目录》（方广锠等，条记目录）
   - 书法类目参照饶宗颐《敦煌书法丛刊》（二玄社，29 册；中文版《法藏敦煌书苑精华》）的十类：拓本、韵书、经史、书仪、牒状、诗词、杂诗文、碎金、写经、道书
   - 写卷之间的关联参照张涌泉的残卷缀合准则
4. 流程：AI 预标 + 所有者审核
5. 每条标注记录来源（人工 / AI 预标 / 外部目录 / 文件名解析）、作者、时间、置信度与依据；AI 预标未经审核不得标为已确认

## 取舍理由

- AI 预标把人工工作从「逐条填写」变为「逐条审核」，6,000 个目录的规模才可行
- 蓝本选择与本地材料最贴近、且有出处的编目：本地以伯希和写卷为主、着眼书法，《敦煌书法丛刊》正是伯希和写卷的书法精选；国图《总目录》的著录项目最细
- 记录来源与置信度，区分「转录」与「判断」（plan.md §5 原则 2、3）

## 影响

- `annotation-workbench`：标注字段、审核流程与历史
- `name-normalization`：字段定义与解析结果作为「文件名解析」来源的标注

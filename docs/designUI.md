# dunhuang-viewer 全局设计理念（designUI.md）

> 设计语言的权威入口。颜色、圆角、阴影的数值以 `static/style.css` 的 `:root` 令牌为准；本文定义理念、页面形态与交互约定。
> 本文从 2026-10-27 的现有实现归纳而来，尚未经过专门的视觉定版；两套视觉并存的问题见 §7，待决策。

## 1. 设计原则

1. **图像第一**：画面区域最大化；控件收进顶部工具栏与可折叠侧栏，不遮挡卷面
2. **玻璃拟态 + 灰白渐变**：浅灰白多层径向渐变底 + 半透明高模糊玻璃面板（`style.css` 注明参考 DeepSeek 风格）
3. **多端可用**：同一套页面服务电脑、手机、平板；触控双指缩放，窄屏侧栏改为抽屉
4. **中文优先**：界面文案、错误提示全部中文，系统中文字体栈
5. **状态可见**：图块生成、拼接生成都有进度；超大卷降级为预览分辨率时在页脚明确告知

## 3. 页面形态

| 页面 | 结构 | 要点 |
|---|---|---|
| 画廊 `/` | 吸顶玻璃顶栏（标题、统计、用户管理入口、搜索、重新扫描、显示全部）→ 分类标签条 → 卡片网格 | 卡片最小宽 232px 自适应列；每批 60 卷，滚到底自动加载；缩略图进入视口才请求；搜索覆盖编号/经名/分类 |
| 查看器 `/view/{卷ID}` | 顶部工具栏 → 画面区（OpenSeadragon）+ 可拖宽右侧栏 → 底部状态 | 工具栏顺序：上一段 / 段名 / 下一段 · 适配 · 1:1 · 缩小 · 放大 · 就地放大 · 还原 · 全屏 · 侧栏开关 · 拼接入口；侧栏为元数据表、分段列表、说明文字；生成图块时画面区遮罩显示进度 |
| 拼接工作台 `/stitch/{卷ID}` | 顶部工具栏 → 画布 + 右侧分片面板 → 底部状态 | 工具栏：缩放、适配、显示接缝、自动建议重叠、重置、保存、生成整卷；面板：背景色、面板宽度、分片列表（启用、上移/下移、对齐、x/y 坐标、旋转（±0.5° 步进）、右裁） |
| 登录 `/login` | 居中卡片 | 内联于 `app.py`，暖色纸底视觉（§7） |
| 管理后台 `/admin` | 用户表 + 新增表单 | 内联于 `app.py`，暖色纸底视觉；危险操作（删除、重置密码）有确认框 |

## 4. 查看器交互约定

- **缩放边界**：`maxZoomPixelRatio: 1.0`（最多放大到原像素 1:1，不做插值放大）、`minZoomImageRatio: 0.5`、`visibilityRatio: 0.35` + `constrainDuringPan`（防止把卷面拖出视野）
- **鼠标**：拖拽平移、滚轮缩放并以指针为参考点；关闭单击与双击缩放（单击留给「就地放大」）
- **触控**：双指缩放，不允许旋转
- **导航图**：右下角 128×84，半透明白底，可视区域用蓝色框标出
- **就地放大**：开启后单击画面即在该处放大；视野历史最多 30 步，Esc 或「还原」逐步返回，历史为空时 Esc 退出就地放大
- **快捷键**：`←`/`→` 切换分段，`+`/`=`、`-` 缩放，`f` 适配，`i` 侧栏，`l` 就地放大，`Esc` 还原 / 退出就地放大（输入框内不响应）
- **降级告知**：卷为预览分辨率时，页脚显示「此卷 N 百万像素（超大）· 可下载原图」

## 5. 响应式

断点 `900px`（`style.css` 与 `stitch.html` 各一处）：

- 查看器：取消双栏；侧栏改为右侧滑出的固定抽屉（宽 `min(86vw, 340px)`），图标按钮放大到 40×40 便于触控
- 画廊：卡片最小宽降到 150px，标题与卡片字号缩小
- 拼接工作台：隐藏右侧面板（窄屏不支持精细拼接）

## 6. 静态资源约定

- `static/` 运行时挂载进容器，改页面无需重建镜像；浏览器缓存由 `StaticFiles` 的协商缓存决定
- `viewer.html` 引用 `style.css` 与 `openseadragon.min.js` 时带版本参数（当前 `?v=20261021b`）；`gallery.html`、`stitch.html` 未带。修改共享资源时同步更新版本参数，避免手机浏览器继续用旧样式
- OpenSeadragon 以压缩版本地托管（`static/openseadragon.min.js`），不依赖外部 CDN

## 7. 已知不一致（待决策）

主界面与登录/管理后台是两套视觉：

| | 主界面（画廊/查看器/拼接） | 登录页 / 管理后台 |
|---|---|---|
| 底色 | 冷灰白渐变 + 玻璃 | 暖色纸底 `#f5efe3` / `#fffdf8` |
| 强调色 | 蓝 `#4f7cff` | 褐 `#8a5a2b`（悬停 `#a06a35`） |
| 字体 | 无衬线系统字体栈 | 衬线：Noto Serif SC / Songti SC |
| 错误色 | `#d9534f` | `#b03a2e` |
| 样式位置 | `static/style.css` | `app.py` 内联 `<style>` |

是否统一、统一到哪一套，列为 plan.md §9 待确认决策；确认后登记 ADR，并在本文定版。

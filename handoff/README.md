# 公开交接入口

旧的审核提示词、执行命令、日志、JSON/JSONL、原始模型报告和校验清单已转为**非公开档案**，不作为公共发布材料。移出公开工作树前已保全原件并核验完整性；公开文档是脱敏衍生版本，不是逐字原文。

- [公开验证摘要](../docs/verification.md)：实际模型/角色、旧候选稳定别名、逐阶段通过/失败/跳过、退出、资源限制与未验边界。
- [交接导航](../HANDOFF.md)：当前许可、安全约定与后续集成入口。
- [catalog规格](../specs/catalog-foundation/spec.md)与[评审隐私修订](../specs/catalog-foundation/review.md)：需求与历史结论保留，真实材料验收仍需单独许可。
- [公开发布隐私规格](../specs/public-release-privacy/spec.md)：本轮发布范围与人工闸门。

详细原件仅供授权核查，不提供假公开链接、私人路径或旧提交映射。原件哈希不冒充编辑后公开产物哈希。删除当前归档不等于已清除Git历史、平台缓存或第三方副本；本入口不宣布全树隐私验收或历史发布完成。
